# Screenshots

The README references these files. Capture them from a running build (`npm start`, `Win+Shift+S`, window at 1920×1080 or larger) and save them here as PNG:

| File | What to capture |
|---|---|
| `boot.png` | Boot sequence: logo, helix and module checks |
| `login.png` | Login / lock screen |
| `home.png` | Home bento desktop with the terminal after `gfetch` |
| `gfetch.png` | Close-up of `gfetch` in the Terminal module |
| `apps.png` | An application overview page with the LAUNCH button |
| `tools.png` | The BLUP workspace (Tools → Breeding & Selection) |

Keep each image under about 600 KB (PNG-8 or a lightly compressed PNG).
