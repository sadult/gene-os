# Keyboard shortcuts

Every **configurable** shortcut can be rebound in **Settings → Keyboard** (conflicts are detected). Letter shortcuts are matched by physical key, so they also work with a Persian keyboard layout.

## Global (configurable)

| Shortcut | Action |
|---|---|
| `Ctrl+K` | Command palette (modules, actions, apps, tools, search results; `>` runs a gsh command) |
| `Ctrl+Shift+F` | Global full-text search |
| `Ctrl+N` / `Ctrl+Shift+N` | New task / new note |
| `` Ctrl+` `` | Terminal |
| `Ctrl+Shift+H` | Home desktop |
| `Ctrl+,` | Settings |
| `Ctrl+.` | Focus mode (hides the dock & page header) |
| `Ctrl+Shift+B` | Notification center |
| `Ctrl+Shift+S` | Scratchpad |
| `Ctrl+J` | Today's journal |
| `Ctrl+Shift+P` | Start / stop pomodoro |
| `Ctrl+Alt+L` | Lock screen |
| `Ctrl+PageDown` / `Ctrl+PageUp` | Next / previous module |
| `F1` | Keyboard help |

## Module navigation (fixed)

| Key | Module | | Key | Module |
|---|---|---|---|---|
| `1` / `Alt+H` | Home | | `Alt+S` | Status |
| `2` / `Alt+T` | Tasks | | `3` / `Alt+R` | Research |
| `4` / `Alt+C` | Courses | | `Alt+N` | Notes |
| `5` / `Alt+L` | Library | | `8` / `Alt+B` | Bookmarks |
| `6` / `Alt+A` | Apps | | `7` / `Alt+X` | Terminal |
| `9` / `Alt+O` | Tools | | `0` / `Alt+P` | Profile |

Digits work while you are not typing in a field; `Alt+` combinations work everywhere.

## Other

| Shortcut | Action |
|---|---|
| `/` | Global search (when not typing) · `?` keyboard help |
| `Esc` | Close dialog / palette / menu |
| `F11` | Fullscreen · `F12` / `Ctrl+Shift+I` DevTools |
| Editors | `Ctrl+S` save · `Ctrl+B` bold · `Ctrl+I` italic · `Tab` indent · `Enter` continues lists |
| Tools | `Enter` in a field = calculate & save to history |
| Palette | `↑↓` move · `Enter` open · `Ctrl+Enter` secondary action (open a file externally, launch an app) |
| Terminal | see [TERMINAL.md](TERMINAL.md) |
| Login screen | `Enter` sign in / unlock (enter the PIN first if one is set) |
